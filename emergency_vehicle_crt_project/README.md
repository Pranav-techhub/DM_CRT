# Emergency Vehicle Priority System (CRT-Based)

This mini-project demonstrates how the **Chinese Remainder Theorem (CRT)** can be applied to real-time traffic signal synchronization to give priority to emergency vehicles (ambulances, fire engines, police cars, VIP convoys).

## Quickstart in GitHub Codespaces

### 1. Run the Interactive Web Simulator
```bash
npm start
```
Opens the interactive web application on Port 3000.

### 2. Run the Simplified C++ Program (2nd-Year Level)
```bash
make run
```
Compiles and runs the pure C++ CRT algorithm without any advanced STL dependencies.
